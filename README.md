# Tic-Tac-Toe
Tic Tac Toe is a simple two-player strategy game played on a 3×3 grid. The game is played between two players — one using 'X' and the other using 'O'. Players take turns marking empty cells on the board, and the first player to align three of their marks horizontally, vertically, or diagonally wins the game. 

 # Features:
 
Two-player mode
Real-time board display
Win & draw detection
Input validation
Simple and user-friendly interface
